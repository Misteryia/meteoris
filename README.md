# METEORIS

3D top-down аркадный шутер на Unity. Игрок управляет турелью на круговой рельсе вокруг космической станции и отбивает волны астероидов.

## Управление

| Действие | Клавиша |
|---|---|
| Прицеливание | Мышь |
| Стрельба (одиночный) | ЛКМ (клик) |
| Стрельба (автоогонь) | ЛКМ (зажать) |
| Переключение режима огня | ПКМ / Tab |

## Две нетривиальные механики

### 1. Recoil-турель на круговой рельсе
Турель скользит по круговой рельсе вокруг станции. У неё нет WASD-управления — перемещение происходит только за счёт отдачи от выстрелов. Каждый выстрел физически толкает турель по рельсе в сторону, противоположную направлению огня. Стрельба одновременно является и атакой, и способом перемещения.

### 2. Тепловая система оружия с двумя режимами огня
У турели нет патронов, но есть тепло. Два режима огня:
- **Одиночный** — медленный, мощный, сильная отдача, не перегревается при аккуратной стрельбе.
- **Автоогонь** — быстрый, слабый, слабая отдача за выстрел, но быстро перегревается.

Перегрев блокирует стрельбу на 3 секунды.

## Инструменты Unity

- **Cinemachine** — top-down камера + Impulse при попаданиях астероидов в станцию.
- **VFX Graph** — взрывы астероидов.
- **Particle System** — космическая пыль.
- **Post-Processing (URP Volume)** — Bloom, Vignette, Tonemapping (ACES).
- **ScriptableObject** — конфиги волн (`WaveConfig`) и характеристик астероидов (`AsteroidData`), параметры оружия (`WeaponData`).
- **Object Pool** — пул снарядов (`ProjectilePool`).
- **Input System** — новый Input System Package для ввода.

## Технический стек

- Unity 6.3 LTS (6000.3.16f1)
- Render Pipeline: URP (Universal Render Pipeline)
- Язык: C#
- Платформа: Windows Standalone

## Структура проекта

Все игровые ассеты находятся в `Assets/_Project/`:
- `Scripts/` — исходный код (Core, Player, Weapons, Asteroids, Station, UI, VFX, Audio)
- `Prefabs/` — префабы астероидов, снарядов, VFX
- `ScriptableObjects/` — конфигурации астероидов, волн, оружия
- `Scenes/` — MainMenu, Game
- `Settings/` — InputActions, URP, Post-Processing
